## 1. Edge AI Paketlerinin Kurulması

`tiovxisp` elemanı ve donanım hızlandırıcılarını (VPAC ISP, MSC, LDC) süren TIOVX yazılımı `t3-edgeai-dev`
paketiyle gelir. [Yapay Zeka Kurulum](/tr/boards/o1/ai/installation) bölümündeki adımlarla paketi kurup
`k3-am67a-t3-gem-o1-edgeai-apps.dtbo` overlayini etkinleştiriniz.

```bash
sudo apt install t3-edgeai-dev
```

Kartta Kamera ISP SDK komutları `root` kullanıcısıyla ve Edge AI ortam değişkenleri yüklenmiş olarak çalıştırılır:

```bash
sudo su
source /opt/t3-edgeai-env
```

<Warning>
Ortam değişkenlerini her yeni kabukta, `build.sh`, `camera-isp-sdk doctor`, `camera-isp-sdk setup` ve `camera-isp-sdk pipeline`
komutlarından önce yükleyiniz. `t3-edgeai-dev` paketi kurulmadan ve `/opt/t3-edgeai-env` yüklenmeden donanım
hızlandırıcıları çalışmaz.
</Warning>

## 2. Paketin Karta Kurulması

[Derleme](/tr/boards/o1/isp/build) bölümünde üretilen paketi karta kopyalayınız.

```bash
scp build/camera-isp-sdk-0.1.0-t3-gem-o1.tar.gz gemstone@<kart-ip-adresi>:
```

Kartta paketi kök dizine açınız.

```bash
sudo tar -C / -xzf camera-isp-sdk-0.1.0-t3-gem-o1.tar.gz
```

| Konum | İçerik |
|-------|--------|
| `/usr/bin/camera-isp-sdk` | Komut satırı aracı |
| `/usr/share/camera-isp-sdk/sensors/` | Sensör tanımlayıcıları (`tiovxisp` bunları okur) |
| `/usr/share/camera-isp-sdk/gst/` | Eklenti yaması, kaynakları ve `build.sh` |
| `/opt/imaging/<sensör>/linear/` | ISP ayar (DCC) dosyaları |
| `/boot/overlays/` | Kamera overlayleri |
| `/lib/modules/<çekirdek>/updates/` | `task drivers` ile derlenen sensör sürücüleri |

## 3. tiovx Eklentisinin Derlenmesi

TI'nin `tiovxisp`/`tiovxldc` eklentisi tanımlayıcı desteğiyle kartın üzerinde bir kez yeniden derlenir.
Betik TI'nin `edgeai-gst-plugins` deposunu sabitlenmiş commit'ten indirir, yamayı uygular, derler ve
mevcut eklentinin yedeğini alarak kurar.

Betiği Edge AI ortam değişkenlerinin yüklendiği kabukta çalıştırınız
([1. Edge AI Paketlerinin Kurulması](/tr/boards/o1/isp/installation#1-edge-ai-paketlerinin-kurulması)).

```bash
/usr/share/camera-isp-sdk/gst/build.sh
```

<Note>
Derleme için kartta `git`, `meson`, `ninja` ve internet bağlantısı gereklidir. Orijinal eklentiye geri dönmek
için `/usr/share/camera-isp-sdk/gst/build.sh --restore` komutunu kullanabilirsiniz. Yeni bir sensör eklemek için
bu adımın tekrarlanması gerekmez; eklenti yaması değişmiş bir paket kurulduğunda gerekir ve `camera-isp-sdk doctor`
bunu bildirir.
</Note>

## 4. Sensör Sürücüsünün Kurulması

| Sensör | Sürücü |
|--------|--------|
| `imx219` | İmajda bulunur, ek işlem gerekmez. |
| `ov5647` | Çekirdekte etkin, ancak imajda bulunmaz: `sudo apt install kernel-module-ov5647-6.12.24-ti` |
| `imx477` | Kamera ISP SDK ile gelir |
| `imx230` | `arducam-pivariety` |

[Sensör Sürücülerinin Derlenmesi](/tr/boards/o1/isp/build#6-sensör-sürücülerinin-derlenmesi) bölümünde derlenen
sürücüler paketle birlikte `/lib/modules/<çekirdek>/updates/` altına kurulur. Sürücüleri çekirdeğe tanıtınız:

```bash
sudo depmod -a
```

## 5. Overlay Eklenmesi ve Yeniden Başlatma

Her sensör için iki overlay bulunur: `k3-am67a-t3-gem-o1-csi0-<sensör>.dtbo` ve
`k3-am67a-t3-gem-o1-csi1-<sensör>.dtbo`. Kameranın bağlı olduğu portun overlayini seçiniz.

<Note>
- Ethernet soketine uzak olan konnektör CSI0, yakın olan konnektör ise CSI1'dir.
- CSI1, hatlarını DSI0 ile paylaşır; CSI1'deki bir kamera DSI0 ekran overlayiyle birlikte kullanılamaz.
- Aynı porta ait başka bir kamera overlayi (örneğin çekirdeğin kendi `csi0-imx219` overlayi) etkinse kaldırınız.
</Note>

```bash
sudo nano /boot/uEnv.txt
```

`uEnv.txt` dosyasının içinde bu tarz tanımlamalar bulunacaktır.

<SnippetUEnv />

Overlay dosya adını `overlays=` satırının sonuna boşluk bırakarak ekleyiniz. Örneğin CSI0 konnektörüne bağlı bir
OV5647 için `k3-am67a-t3-gem-o1-csi0-ov5647.dtbo` dosya adını kullanmalısınız.

<SnippetUEnvEdit />

Ardından kartı yeniden başlatınız.

```bash
sudo reboot
```

## 6. Kurulumun Denetlenmesi

`camera-isp-sdk doctor` komutu overlayin, sürücünün, yamalı eklentinin ve DCC dosyalarındaki kimliklerin doğru olup
olmadığını denetler.

<SnippetIspDoctor />

<Warning>
`tiovxisp` ve TIOVX `/dev/mem` erişimi gerektirdiğinden `doctor`, `setup` ve ISP kullanan tüm komutlar `root`
kullanıcısıyla, Edge AI ortam değişkenlerinin yüklendiği bir kabukta çalıştırılmalıdır:

```bash
sudo su
source /opt/t3-edgeai-env
```
</Warning>

`camera-isp-sdk setup` komutu karta bağlı kameraları bulur, tanımlayıcıdaki modu sensör → CSI-2 köprüsü → alıcı hattı
boyunca ayarlar ve `/dev/video-<sensör>-cam0`, `/dev/v4l-<sensör>-subdev0` bağlantılarını oluşturur.

<SnippetIspSetup />

<Note>
`/dev` altındaki bağlantılar her açılışta yeniden oluşturulmalıdır. Kamerayı bir servisle kullanıyorsanız
`camera-isp-sdk setup` komutunu servisin `ExecStartPre` satırına ekleyebilirsiniz.
</Note>

Kurulum tamamlandıktan sonra kamerayı [Kullanım](/tr/boards/o1/isp/usage) bölümündeki komutlarla
çalıştırabilirsiniz.
